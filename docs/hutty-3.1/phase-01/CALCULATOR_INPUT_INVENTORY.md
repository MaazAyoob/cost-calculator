## 1. INVENTORY METHODOLOGY & SCOPE

This document provides a line-by-line inventory of every input parameter currently present in the Hutty calculator. It maps each field's lifecycle: from the user interface capture point, to Zustand persistence (`useWizardStore.ts`), through the `buildInput()` bridge into the forward calculation pipeline (`src/calculation-engine/calculator.ts`), down to the final Works BOQ and printable report outputs.
